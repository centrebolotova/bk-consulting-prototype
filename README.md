# Прототип сайта BK consulting

Прототип для согласования, не рабочий сайт. Страницы закрыты от поисковиков.

- `index.html` — главная;
- `proverka-uchastka.html` — шаблон страницы услуги;
- `src/` — исходники; сборка: `python src/build.py` (стили и скрипты вшиваются в каждую страницу).

Внизу слева кнопка «Варианты оформления»: первый экран и цвет фона.
